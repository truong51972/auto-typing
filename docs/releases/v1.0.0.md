# Auto Typing v1.0.0

First ready-to-download Windows release of **Auto Typing**, a local desktop typing utility based on Python and PySide6.

## Highlights

- Portable **Windows x64 executable**: download the `.exe` asset and launch it without installing Python or `uv`.
- **Hybrid Typing (UniKey)** for text mixing English and Vietnamese; bypasses common Telex collisions such as `as` → `á`.
- Other typing modes: clipboard paste, direct Unicode injection, and physical keyboard events.
- Text normalization, live input preview, cancellation with F8, countdown, progress, and editable timing.
- Compact layout with scrollable settings and defaults of **10 ms key interval** and **5 ms key hold**.

## Download

Download `AutoTyping-v1.0.0-windows-x64.exe` from **Assets** and run it on Windows 10/11 (x64). No installation is required.

The executable is **unsigned**, so Windows SmartScreen may warn before the first launch. Only run an executable that you trust, and use the included SHA256SUMS.txt to check download integrity.

## Important limitations

- Automated CI checks that the bundled GUI launches but **does not test real keystrokes into Windows applications**. Test with Notepad and UniKey before using it in another application.
- Some applications and IMEs handle mixed Unicode/physical input differently. UniKey must be configured for Vietnamese / Telex for physical Vietnamese typing.
- Clipboard Paste replaces the clipboard contents. Enter may submit forms or chat messages.
- Windows only; this release is not code signed.
